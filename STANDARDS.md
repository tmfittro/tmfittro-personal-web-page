# STANDARDS.md

## 1. Project Overview

This is a personal landing page for Taryn Fittro, a Business Analytics student at the University of Iowa. The purpose of this site is to showcase skills, projects, and career interests in analytics and real estate to recruiters and hiring managers.

---

## 2. Technical Standards

Languages:
- HTML5 (semantic elements)
- CSS3 (external stylesheet only)

Folder structure:
- index.html
- /css/stylesheet.css
- /images/headshot.jpg

Rules:
- No inline CSS
- No JavaScript
- Static site only
- Fully responsive design

Accessibility:
- All images must have alt text
- Proper heading structure
- Clear readable text

---

## 3. Design Standards

Color palette:
- White background
- Dark text (#212529)
- Accent color (navy or teal)

Typography:
- Font: Inter (Google Fonts)
- Clean and professional

Layout:
- Centered content
- Simple sections (About, Skills, Projects, Contact)
- Good spacing between sections

Imagery:
- Professional headshot only

Tone:
- Professional
- Approachable
- Data-driven
